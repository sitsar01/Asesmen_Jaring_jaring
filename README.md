# Asesmen Jaring-Jaring Bangun Ruang

Aplikasi asesmen interaktif materi jaring-jaring bangun ruang dalam Bahasa Indonesia.

## Isi

- **Kuis:** 15 soal pilihan ganda tentang jaring-jaring kubus, balok, prisma segitiga, limas segiempat, tabung, kerucut, dan bola. Setiap soal dilengkapi umpan balik dan alasan, skor berjalan, serta pembahasan di akhir.
- **Pasangkan:** 8 pasangan bangun ruang dengan susunan jaring-jaringnya, dengan hitungan percobaan, kesalahan, dan skor akhir.

## Cara memakai

Buka `index.html` di peramban, atau aktifkan GitHub Pages dari cabang utama untuk membagikannya lewat tautan.

## Materi yang dicakup

Kubus (6 persegi), balok (3 pasang persegi panjang sama besar), prisma segitiga (2 segitiga + 3 persegi panjang), limas segiempat (1 persegi + 4 segitiga), tabung (2 lingkaran + 1 persegi panjang), kerucut (1 lingkaran + 1 juring lingkaran), dan bola sebagai pengecoh karena tidak memiliki jaring-jaring yang tepat.
